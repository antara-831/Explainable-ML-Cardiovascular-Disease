# Explainable ML for Cardiovascular Disease Prediction

A machine learning classification project to predict cardiovascular disease using clinical features, enhanced with SHAP (SHapley Additive exPlanations) for model interpretability.

## Models & Performance
- **Logistic Regression:** 80.33% Test Accuracy
- **Random Forest Classifier:** 85.46% Cross-Validation Accuracy | 77.05% Test Accuracy

## Tech Stack
- Python, Pandas, NumPy, Scikit-Learn, SHAP, Matplotlib, Seaborn
